## 🗡️ About The Project

**Zoro** is a cinematic web experience dedicated to Roronoa Zoro — the swordsman who follows his own path, lives by his principles, and never breaks his promises.

This project explores the intersection of **frontend development, visual storytelling, and immersive web experiences**.

Rather than being just another character-themed website, Zoro aims to create an experience that captures the atmosphere and personality of one of One Piece's most iconic characters.

> "If I can't even protect my captain's dream, then whatever ambition I have is nothing but talk."

---

## ✨ Vision

- 🎬 **Cinematic Experience** — Create an immersive visual storytelling experience.
- ⚔️ **Zoro-Inspired Design** — A visual identity inspired by the Three-Sword Style.
- 🌑 **Atmospheric Interface** — Build a distinctive experience through visual design and presentation.
- 🧭 **Interactive Storytelling** — Make the journey more engaging through web interactions.

## 🚀 Getting Started

Want to explore the project locally? Follow these steps.

### 1. Clone the repository

```bash
git clone https://github.com/BhaveshDave09/Zoro.git
```

### 2. Navigate to the project

```bash
cd Zoro
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit:

```text
http://localhost:3000
```
