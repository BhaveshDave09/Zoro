## 🩸 ABOUT THE PROJECT

Not every legend is born with a crown. Some are forged through discipline, ambition, sacrifice, and an unbreakable promise.

**ZORO** is a cinematic and interactive web experience inspired by Roronoa Zoro — the swordsman who dreams of becoming the World's Greatest Swordsman.

This project explores the intersection of **frontend development, creative UI/UX, and immersive visual storytelling**.

More than just a character-inspired website, ZORO aims to capture the atmosphere, personality, and spirit of one of the most iconic characters in anime.

> ⚔️ Three swords. One dream. Zero excuses.

## 🚀 GETTING STARTED

Want to explore the project locally?

Follow these steps to get started.

### 1️⃣ Clone the repository

```bash
git clone https://github.com/BhaveshDave09/Zoro.git
```

### 2️⃣ Navigate to the project

```bash
cd Zoro
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Awaken the development server

```bash
npm run dev
```

### 5️⃣ Enter the world

Open your browser and visit:

```text
http://localhost:3000
```

🔥 You're ready to explore!
